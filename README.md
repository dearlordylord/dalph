# Dalph

Dalph helps teams deliver work from a graph of tasks. It finds tasks that are
ready, runs them concurrently within configured limits, and manages their
worktrees, reviews, retries, integration, recovery, and cleanup.

Your task tracker owns the tasks and their dependencies. Git owns the source
history and integrated changes. Dalph coordinates the work and records what
happened along the way.
